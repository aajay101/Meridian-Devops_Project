# Meridian

A DevOps-enabled Placement Management Portal.

## Technology Stack

- Backend: Flask
- Frontend: Vue 3 + Vite
- Database: PostgreSQL
- Caching: Redis
- Background Processing: Celery
- Containerization: Docker and Docker Compose
- CI/CD: GitHub Actions

## Project Structure

- src/backend: Flask application
- src/frontend: Vue application
- tests: Automated test suites
- docker: Docker configuration
- docs: API specifications and architecture documentation
- .github/workflows: CI/CD workflows

## Development Status

Initial repository restructuring completed.
PostgreSQL migration is planned as the next development milestone.
